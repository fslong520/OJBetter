使用帮助

🚀 快速开始

  1. 在 OJ 网站上打开任意编程题
  2. 点击浏览器工具栏上的 🦉 图标，或按 Ctrl+Shift+H 打开侧边栏
  3. 在输入框中粘贴题目，或直接点击下方按钮开始
  4. 选择模式：启发式引导（带方向地学）或 灵光一闪（头脑风暴）

💡 使用方式

  • 🦉 扩展图标：在 OJ 页面上点击工具栏图标，打开侧边栏
  • ⌨️ 快捷键：按下 Ctrl+Shift+H 快速打开/关闭侧边栏
  • 📋 手动粘贴：在侧边栏输入框中粘贴题目内容，选择模式开始
  • 🎯 页面按钮：在支持的 OJ 网站上，题目下方会出现「✨ 灵光一下，开始思考」按钮
  • ✂️ 划词菜单：选中任意文本，右键选择「灵光一下，小智帮你」

🎯 两种模式

  • 🔍 启发式引导：AI 教练根据你的回答动态调整教学节奏——理解偏了纠偏，思路对了推进，写了代码引导调试。不直接给答案，像真人教练一样思考你此刻需要什么
  • ✨ 灵光一闪：AI 扮演「质疑者」「联想者」「出题人」三重角色轮换，和你一起天马行空地探索题目的更多可能性

📚 其他功能

  • 🌐 翻译：将英文题目翻译成中文，保留数学公式
  • 📜 历史记录：查看所有提问记录和对话历史，方便复习
  • 📊 明日推荐：根据学习情况生成个性化练习推荐
  • 📄 导出报告：将学习记录导出为 PDF 报告
  • ⚙️ 设置：自定义 AI 模型、教练风格、温度参数等

❓ 常见问题

小智没有回复怎么办？

检查设置中的 API 配置是否正确，确保网络连接正常。免费模型无需 API Key，如使用自定义 API 请确认地址和密钥无误。

如何清除所有历史数据？

打开历史记录面板（📜），点击底部的「清除全部记录」按钮。

支持哪些 OJ 网站？

支持国内外 70+ 主流 OJ 和竞赛网站，包括洛谷、AcWing、牛客、LeetCode、Codeforces、AtCoder 等。

两种模式有什么区别？

启发式引导适合初学或需要循序渐进解题时使用；灵光一闪适合做完题后拓展思维，或卡住时换角度想问题。
