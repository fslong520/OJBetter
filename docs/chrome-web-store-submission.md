### OJBetter - 渐进式 AI 编程助教

**AI 像教练一样引导，而不是像答题机一样给答案。**

OJBetter 是一款面向 8-16 岁信奥赛学生（CSP/NOI/GESP）的 Chrome 扩展，定位为**渐进式 AI 编程助教**。与市面上直接输出答案的 AI 工具截然不同，OJBetter 采用独特的四阶段引导法，像一位耐心的教练，逐步启发学生独立思考。

#### 四阶段引导法

| 阶段 | 说明 |
|------|------|
| **🧠 理解题意** | AI 引导学生用自己的话复述题目，确保真正理解问题在问什么 |
| **🔍 启发式引导** | 给出方向性提示（考点分析 + 思维引导），启发解题思路 |
| **📋 画出思路** | 生成 ASCII 流程图与关键步骤，要求学生对流程理解达 80% 以上 |
| **📝 伪代码与调优** | 从伪代码过渡到真实代码，最后引导调试与优化 |

每个阶段 AI 只给出恰到好处的提示，从不一次性抛出完整答案。学生在多轮对话中自己思考、自己发现，真正学会编程。

#### 语音交互

- **语音输入**：点击麦克风按钮直接说出思路，AI 自动识别并填入对话框
- **语音播报**：AI 回复可一键朗读，适合低龄学生或不方便看屏幕的场景
- 基于 Web Speech API，所有语音数据均在本地处理，不上传服务器

#### 多模态支持

- 支持上传/粘贴题目截图
- 图片作为附件随对话发送
- AI 可识别图片中的题目内容并加以引导
- 图片预览条管理，可随时删除

#### 一键翻译

- 将英文编程题目翻译为中文 Markdown
- 完整保留数学公式、输入输出格式、样例数据
- 只翻译不解释，纯粹的题目转换工具
- 支持 LeetCode、Codeforces、AtCoder 等主流 OJ 平台

#### 学习报告导出

- 一键导出当前对话为 PDF 学习报告
- 包含完整的四阶段引导过程记录
- 便于家长/老师了解学生思考过程
- 本地生成，不上传任何数据

#### 隐私与安全

- 所有 AI 对话内容仅存储在本地浏览器中
- 不收集任何个人身份信息
- 不使用第三方分析工具
- 开源项目（MIT 许可），代码透明可审查

#### 技术特性

- Chrome Side Panel 侧边栏界面，不打断浏览体验
- AI 流式输出，思考过程与回答实时显示
- Storage 流式传输架构，告别端口断开问题
- 自动捕获 OJ 页面题目，零操作启动
- 支持 OpenCode Zen 免费模型 / 自定义 OpenAI 兼容 API
- 快捷键 Ctrl+Shift+H 快速开关面板

#### 适用平台

支持 LeetCode、洛谷、AcWing、Codeforces、AtCoder、牛客网等主流编程题库和 OJ 平台。

---

**OJBetter 不自诩替代老师，只做学生身边那个永不疲倦的 AI 教练。每一次引导，都在为独立思考铺路。**

# OJBetter 隐私政策

**最后更新日期：2026 年 6 月 3 日**

感谢使用 OJBetter（以下简称"本扩展"）。本隐私政策说明本扩展如何收集、使用和保护您的信息。

### 信息收集与使用

#### 1. AI 对话内容

本扩展的核心功能是与 AI 进行编程学习对话。对话内容（包括您输入的文字、上传的图片）将：

- 发送至您配置的 AI API 服务（默认：OpenCode Zen API）进行处理
- 存储在您浏览器的本地存储（`chrome.storage.local`）中，用于历史记录功能
- **不会**传输至任何第三方服务器（除您配置的 AI API 服务外）
- **不会**用于任何训练目的

#### 2. 语音数据

本扩展的语音输入功能使用 Web Speech API：

- 语音识别在**本地浏览器**中完成
- 识别的文字结果会发送至 AI API 进行处理
- 原始语音数据**不会**被上传或存储
- 语音播报功能仅在本地合成音频

#### 3. 图片数据

本扩展支持上传题目截图：

- 图片作为对话上下文发送至 AI API 服务
- 图片临时存储于浏览器内存中，关闭侧边栏后自动释放
- **不会**持久化存储图片文件

#### 4. 自动收集的信息

本扩展**不收集**以下信息：

- 个人身份信息（姓名、邮箱、电话号码等）
- 浏览历史记录
- 账号密码
- Cookie 或其他网站数据
- 设备信息或指纹

#### 5. 第三方服务

本扩展默认使用 OpenCode Zen API 作为 AI 服务提供商。您可以在设置中更改为自定义 API。请查阅对应服务提供商的隐私政策以了解其数据处理方式。

#### 6. 数据存储

| 数据类型 | 存储位置 | 存储期限 |
|----------|----------|----------|
| AI 对话历史 | 浏览器本地存储 | 直至用户手动清除 |
| 扩展设置 | 浏览器本地存储 | 直至用户卸载扩展 |
| 学习报告（PDF） | 用户本地下载 | 由用户自行管理 |

#### 7. 用户权利

您拥有对数据的完全控制权：

- **查看**：在扩展侧边栏中查看历史记录
- **删除**：在扩展界面中一键清除所有历史数据
- **导出**：将对话导出为 PDF 学习报告
- **卸载**：卸载扩展后，所有本地数据自动清除

#### 8. 儿童隐私

本扩展面向 8-16 岁学生。我们：

- 不收集儿童的任何个人身份信息
- 不追踪儿童的上网行为
- 不展示任何广告
- 不包含付费内容或订阅

#### 9. 政策更新

本隐私政策可能不时更新。更新后，将在本页面顶部显示新的生效日期。

#### 10. 联系方式

如有任何隐私相关问题，请通过以下方式联系我们：

- GitHub Issues：https://github.com/fslong520/OJBetter/issues
- 项目主页：https://github.com/fslong520/OJBetter
