# OJBetter：我把自己的引导方法蒸馏成了一个 AI 智能体

## 为什么做这个东西

我教信奥。这些年一直在打磨一套引导式教学方法，核心是苏格拉底式追问与脚手架理论的结合——不给答案，而是在学生的最近发展区内搭建台阶，每级台阶只比当前水平高一点点，刚好够得着。什么时候给提示、给到什么程度、什么时候撤掉支架让学生独立走，这些判断标准已经形成了一套系统。

但我不能同时坐在每个学生旁边。

所以我把这套方法放进了 AI 里，做了个浏览器扩展叫 OJBetter。你可以把它理解成我的一个智能体分身——它不像 ChatGPT 那样直接给答案，它会运用这套教学法，一步步引导学生自己把题解出来。

## 四阶段引导

这是核心。整个流程基于认知负荷理论和渐消式提示原则设计，分成四个递进阶段。

**理解题意。** 学生用自己的话复述题目。这一步对应教学中的"前理解激活"——十道做不出的题，大半是题没读懂。能用自己的语言重新编码题目信息，才算真正完成了语义解码。读懂了再往下走，读不懂 AI 会换角度引导，直到学生自己能说清楚为止。

**启发式引导。** AI 给出方向性提示——这道题考什么知识点、大概往哪个方向想。但只给到"你离答案还有多远"的程度，不点透。这是刻意保留的认知间隙，目的是激发学生的自主探索动机。教育心理学里有个概念叫" desirable difficulty"——恰到好处的困难，最能促进深度学习。

**画出思路。** AI 生成 ASCII 流程图，把抽象逻辑转化为可视化的结构。这一步是思维的外显化过程——光在脑子里想是模糊的，画成流程图，每个判断分支、每个循环出口都必须明确。学生跟着过一遍，逻辑漏洞自己就暴露了。

**伪代码与调优。** AI 给出伪代码框架，但关键的边界条件、循环逻辑留空，要学生自己补。补完还得自己调试。这一步是认知负荷的逐步释放——从完整的脚手架过渡到自主完成，渐消式提示的最后一环。

四阶段走完，代码是学生自己写出来的。整个过程流式输出，AI 的推理过程实时可见，学生能观察到一个有经验的解题者是如何思考的——这是一种隐性的元认知训练。

## 为什么这对 OIer 有用

信奥赛考的不是你会不会复制代码。考的是你拿到一道没见过的题，能不能自己把解法推出来。

市面上大多数 AI 编程工具在做相反的事——你把题贴进去，它洋洋洒洒一大段话，最后把代码吐出来，大部分孩子都会禁不住诱惑直接复制粘贴。
你 AC 了，但下次遇到同类题还是不会。这跟刷题解的毛病一样，学生绕过了完整的认知过程，只拿到了最终结果。

OJBetter 的做法不一样。它不是答题机，是一个嵌入了系统化教学法的智能教练。它的每一次提问、每一个提示的粒度，都经过设计。你卡在哪儿，它从你的最近发展区边缘开始推。你走对了，它提升追问深度。你暴露了理解偏差，它调整提示角度。整个过程基于教学决策框架，而非简单的问答匹配。

跟真人教练的区别只在于——它二十四小时在线，不用约时间，不会不耐烦。

## 附带的能力

除了核心引导，还有一些顺手做的功能，覆盖了刷题的完整链条。

**一键翻译。** 英文题目转中文 Markdown，数学公式、输入输出格式、样例数据完整保留。只翻译不解释，纯粹做转换工具，不做额外干扰。

**语音播报。** AI 回答可以一键朗读，调语速、选音色。不想看屏幕的时候闭着眼睛听。

**历史记录。** 侧边栏右上角打开，所有对话都在。点任一条重新加载，方便复盘。

**PDF 学习报告。** 当前对话一键导出为 PDF，整理笔记或发给老师都行。

**明日推荐。** AI 根据学习情况生成个性化练习建议。

五十多个 OJ 平台全覆盖，洛谷、Codeforces、AtCoder、AcWing、LeetCode 都在支持列表里。装一个，不管在哪个站刷题都能用。

## 配置和隐私

默认模型免费，用 OpenCode Zen，不需要 API Key，不用绑卡，装好即用。也支持自定义 OpenAI 兼容接口。

所有对话数据存在本地 chrome.storage，不上传服务器。MIT 开源，代码全公开。

## 安装

三种方式：

1. Edge 商店搜"OJBetter"，点安装
2. Chrome 用户去 GitHub Releases 页面下载 crx 文件，拖进扩展页
3. 或者直接 `git clone` 源码，在 `chrome://extensions` 开启开发者模式，加载已解压的扩展

快捷键 Ctrl+Shift+H 打开/关闭侧边栏。
